# 48 · Web App 六模块演示原型

日期：2026-11-05。分支 `codex/web-app-prototype`，基于 master `5ef1bde`（第 47 轮原型设计）。进度 47 已被 Harbor 补修和原型设计各用一次，本轮记为 48。

## 做了什么

在 `frontend/` 新建 React、TypeScript、Vite 工程，不改 `src/harness`。六个一级模块都在侧栏：工作台、评测集、实验中心、轨迹分析、实验对比、模型与连接。轨迹分析是独立入口，实验详情里的样本打开同一组件和同一份数据。

数据是标明的演示记录。终端题使用仓库已固定的 5 道 Terminal-Bench 名称和指纹；GSM8K 四题是自拟算术，不是官方原文。SWE-bench 只显示目录，不能创建实验，也没有分数。

模拟运行由前端状态推进：开始后约每秒更新墙钟，运行中的样本约 2 秒结束，取消后计时和进度停止。未完成样本记为取消，不记为模型失败。环境异常的 token 和分数是「不适用」，缺失是「未记录」，都不填 0。缓存已计入输入时，页面不把缓存再加一遍。不同评测集不合并总分。对比用百分点，并写明 Agent、预算或执行环境不同时不能把变化归因于模型。

自然语言只解析设计文档里的明确例子，结果填进可编辑表单。不支持的输入会说明原因。「连接真实后端」禁用。模型与执行环境的测试只改本地状态。

## 限制

- 成绩、轨迹和连接状态都是演示，不能写成真实实验或 Harbor 验收。
- 没有从 `runs/` 读取归档，也没有只读 API。
- 公开榜导出和「连接真实后端」未实现，按钮禁用并有说明。
- 取消后的运行不能续跑，需要新建实验。
