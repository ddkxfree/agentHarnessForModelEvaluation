# Harbor运行进度与离线报告

`harness harbor run`和`resume`现在每10秒打印累计执行耗时、各阶段任务数量与最多8个任务的最近活动，优先显示未结束任务；停止后的容器清理、归档与报告生成也会提示。阶段从已有日志与结果推断，Cursor事件可显示工具名称和命令／路径摘要。进度内容经过凭据脱敏及终端控制字符清理。

“N秒未见新日志”不等于卡死：CLI、安装器、模型端和容器产物可能缓冲输出。仅能报告已公开且落盘的活动，不提供虚构的百分比、逐步token或隐藏API重试。准备检查会先打印提示；其期限与执行期限分别沿用已有配置。

运行结束（包括成功、失败、取消后能导入的记录）自动在运行目录生成`report.html`，终端打印完整路径。生成报告失败只产生report_error，不改变任务得分或删除证据。

报告是独立HTML，直接用浏览器打开，不需要启动Harbor、Docker或本地服务，不加载远程依赖、不调用任何分析模型。包括任务得分、阶段耗时、已报告用量、结构化轨迹中的消息与工具调用／返回，以及折叠的日志和评分证据。未知用量保留未知，缓存不要重复计入输入，费用不等同账户扣费。

已有运行可离线补生成：

```bash
.venv/bin/harness harbor export runs/<run-directory>
```

只读取导入后的脱敏`raw/`、`harbor_run.json`与`trials.jsonl`，不读取私有`local/`原件；过期脱敏版本须先执行`harness harbor rebuild`。报告对内容作HTML转义，不执行日志中的脚本，也不加载日志里的远程图片。单文件文本预览上限2MB，超限有明确提示，完整文件仍在raw；非文本产物列出名称，备份交付物时须同时保留raw。整份运行目录包含私有local原件，不应当作公开分享包。

若某CLI没有轨迹，报告显示现有日志及缺失说明。格式可解析但缺少的历史字段不会被补造。
