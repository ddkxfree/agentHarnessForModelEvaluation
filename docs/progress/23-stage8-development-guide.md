# 23 · 阶段八开发交接指引

日期：2026-10-25。本轮只整理开发计划，未实现或运行接入 Agent。

已有方向散见路线图、05 的十阶段验收表和 next-stages。现整理为可直接交给 Opus 的 [阶段八开发指引](../stage8-plan.md)。

第一版范围：一个固定来源的小任务集，程序化 Agent 生成 adapter 与测试，执行检查，接收诊断并有限次修复；独立冻结的正反例验收，最终导出候选 diff，由人评审。复用已有平台能力，不做任意 Benchmark 的全自动接入。

验收分为工作流／MockModel 回归、真实 Agent 接入两个层次。开发时无需云端部署大模型，真实验证使用本地模型或外部 API。阶段六 J1／J2 仍保留小补修，不能因开始阶段八就标为已解决。

交付分三批：规格与独立验证 → Agent 循环与归档 → 端到端候选 adapter、文档与 PR。详见开发指引。
