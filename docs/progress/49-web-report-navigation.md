# 第 49 轮：总览、完整报告与说明页

日期：2026-11-05。

## 本轮变更

按用户要求直接优化 Cursor 的 frontend 工程，六个一级模块保持不变。工作台删除逐实验堆叠指标，显示关键指标、运行中与最近实验，并链接完整报告。实验中心详情保留运行操作与样本，完整配置、统计和事件进入报告；报告不提供启动、编辑或取消操作。

对比页先展示成功率变化、用量和进退步样本，配置、能力标签及完整分组进入带 a/b 参数的报告页。轨迹页面提供独立完整日志和评分证据入口，默认同页导航，另提供新标签页。通用口径集中到 /help/metrics。

样式调整为浅灰蓝色、克制的指标卡和表格，保持原有指标逻辑。演示状态从 sessionStorage 迁移到同源 localStorage，支持 storage 事件同步；报告和独立证据页不驱动模拟，不可见页暂停推进。跨设备归档、不可变快照和后端调度未实现。
